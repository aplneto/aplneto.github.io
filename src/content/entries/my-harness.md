# My Agent Harness (so far)

There are a lot of templates for agent harnesses online. From coding harnessess, to game dev harnesses, hacking harnesses and so on. If you want to do something with AI, there's likely a harness for you somewhere. So here is mine.

My harness is sort of a duck, it wasn't build to do a nothing particularly very well, but it helps with pretty much everything I study. It is not aimed at full automation of anything, nor is it a guide. It is more of a collaborative effort for me and my buds (that's how I tend to call my AI assistants).

## Pi

Though I use a different set of tools at work, for my personal projects, studies and certifications I tend to use [Pi](https://pi.dev/). It is a minimalistic AI assistant that doesn't come with a lot of builtin stuff
